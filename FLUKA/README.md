# FLUKA Simulations

This directory contains the input files, configurations, and scripts associated with the FLUKA simulations
performed for the Láscar volcano neutrino study.

## Contents

- `inputs/`: FLUKA input files and configurations.
- `scripts/`: Simulation and processing scripts.

## Documentation

Simulation parameters, geometry definitions, materials, and particle sources will be documented as the 
original files are incorporated.
