# Honda Atmospheric Neutrino Flux

This directory contains atmospheric neutrino flux tables calculated by Honda and collaborators.

The file `kam-nu-20-01-000.d` provides atmospheric neutrino flux predictions for the Kamioka site in Japan.

These data are used as an initial approximation for the atmospheric neutrino flux in the Láscar volcano neutrino simulation project.

## Original Source

Honda Atmospheric Neutrino Flux:

http://www-rccn.icrr.u-tokyo.ac.jp/mhonda/public/

## Reference

M. Honda et al., "Atmospheric neutrino flux calculation using the NRLMSISE-00 atmospheric model", Physical Review D 92, 023004 (2015).

https://doi.org/10.1103/PhysRevD.92.023004
